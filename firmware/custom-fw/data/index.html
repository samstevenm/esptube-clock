ESPTube Control

connecting…
Built-in fallback UI. The full console — widgets, characters, live video, scenes, WiFi setup — is served by the clock too: open the ESPTube Helper. For camera / screen / tab capture run python3 tools/console.py on your computer and use http://localhost:8765 — browsers only allow capture on a secure page, and this one is plain http. On an iPhone: open it in Safari, Share → Add to Home Screen, and it runs as an app (works on the clock's own hotspot with no internet).
Text uses a basic built-in font — emoji & rich fonts aren't supported here; use tools/helper.html for those (and for images).

You're on the clock's own network (esptube-setup). Pick your WiFi below and enter its password — the clock joins it, remembers it, and drops this hotspot ~90 s later. Then find it on your network as http://esptube.local.
Saved networks (the clock joins the strongest one it can see; up to 8):
Recovery hotspot: esptube-setup · password — · 192.168.4.1. It comes up by itself when no saved network is in range (a move, a new router, an outage), and from the clock's menu (long-press MODE → AP). Everything else — the clock, faces, messages, the USB shell — works with no WiFi at all.
